# Product release checklist

- [ ] Confirm ownership and distribution permission.
- [ ] Run live tests in each supported Revit version.
- [ ] Record input, output, demonstration and known limitations.
- [ ] Package and verify installation, update and removal.
- [ ] Publish version, release date, checksum, compatibility and licence.
- [ ] Test the download from its actual public destination.
- [ ] For paid tools, verify checkout, payment confirmation and delivery.
- [ ] Retain actual feedback and usage evidence, with permission.

Download counts do not establish active usage. Illustrations do not establish live functionality.
